# Architecture decision records (ADR)

One file per decision, named `NNNN-short-title.md` (for example `0001-choose-database.md`). Copy [template.md](template.md) to start a new one.

## Status

- **Proposed:** under discussion, not yet decided.
- **Accepted:** decided and in force.
- **Deprecated:** no longer applies, and nothing replaces it.
- **Superseded:** replaced by a newer ADR, which must be linked from the old one.
