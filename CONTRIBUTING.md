# Contributing

## Workflow

1. Open an issue describing the change, or pick an existing one.
2. Create a branch from `main` named `<type>/<short-description>` (for example `feat/add-login`).
3. Make the change, updating the [documentation](docs/requirements/README.md) and [ADRs](docs/adr/README.md) it affects.
4. Open a pull request using the template.

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/): `<type>: <description>` (for example `fix: handle empty input`).
