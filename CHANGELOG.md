## [0.1.0] - 2026-11-19

### Added

- Website on GitHub Pages listing localities of Asturias, each with a button to subscribe to its holiday calendar.
- Generator that validates the yearly holiday data and builds one iCalendar file per locality and the website.
- Workflows to check pull requests and to publish when the holiday data changes or on demand.
- Holiday data for 2026 and 2027 for Oviedo, Gijón, Avilés, Llanera, Siero and Lugones.
- Requirements, architecture decision records and the guide to update the holiday data.
